# VisionDesk

Мощный одностраничный дашборд для локального инференса нейросетей в браузере. Позволяет загружать видеоисточники (камера, файл, HLS-поток) и применять к ним Object Detection и Classification модели (ONNX, TF.js) в реальном времени с использованием WebGPU/WASM.

## Запуск проекта

**Требования к браузеру:** 
- Google Chrome 113+ / Edge 113+ (для стабильной поддержки WebGPU).
- Safari 16.4+ (только WASM фолбэк, WebGPU экспериментальный).

```bash
# 1. Установка зависимостей и копирование WASM файлов
npm install

# 2. Запуск сервера разработки
npm run dev
